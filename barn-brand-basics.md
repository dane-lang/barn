# barn-brand-basics

Basics for the pole barn construction drawing set and its web presence. Lowercase-hyphen naming throughout.

## color palette

| role | color | hex |
|---|---|---|
| canvas anchor | cream | `#FFFBBF` |
| text and linework | charcoal | `#333333` |
| structure — headers, rules, dimensions, note titles | navy | `#1B2A47` |
| primary action and alerts | oxblood | `#7A1220` |
| secondary, links, future/deferred items | pine | `#0B5E3A` |
| grounding — footers, secondary borders | brown | `#3D2314` |

Supporting tones derived for the cream field: muted-gold hairlines `#C6B667`, soft-gold fills `#F3E9A6` / `#EEDF9A`, near-white callout panels `#FFFEF2`.

## two-accent rule

Oxblood and pine each carry one job and are never placed adjacent at equal weight.
- **Oxblood** = act now / caution: primary buttons, "not for permit," confirm-with-engineer callouts.
- **Pine** = secondary and deferred: secondary/outline buttons, links, and anything marked future or deferred on a sheet.
- **Navy** stays structural (built/current framing, headers, dimensions). Charcoal is linework. This keeps red + green from reading as "holiday."

## typography

- **Poppins** — display: sheet titles, headers, section labels. Weights **300** (large titles) and **400**.
- **Manrope** — body: notes, dimensions, table text. Weights **400** with **300** for secondary lines.
- Weights are limited to **200 / 300 / 400** only. Hierarchy is carried by size, navy, and Poppins-vs-Manrope — not by bold.
- Sentence case. No all-caps labels in the web chrome.

## style

Cream "clipboard / legal pad" ground with charcoal linework — architectural precision, quiet fine print, rural-Americana warmth without a specific brand. Hairline rules over fills. One-scale-per-sheet drawings. Schematic set — not for permit; dimensions govern.
